# devops-testing

A personal DevOps learning repository where I practice core tools and
document what I learn step by step.

## What's inside
- **Git & GitHub**: install, global config, add/commit/push, and
  authentication with tokens and SSH keys
- **Docker**: running containers, custom networks, container-to-container
  communication by name, and cleanup commands
- **Deployment**: hosting a small PHP + MySQL/MariaDB app (Apache, PHP,
  MariaDB) inside an Ubuntu container using a shell script

## Goal
Build a solid DevOps foundation through small, practical projects, and
later move on to Docker Compose and cloud hosting (e.g. AWS EC2).

## Notes
Each topic has its own `.md` file with commands and short explanations.
